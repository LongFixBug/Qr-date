# Qr-date

Một landing page nhỏ dành cho lời mời hẹn Chủ nhật.

## Trải nghiệm

- Vào trang sẽ thấy một phong thư.
- Chạm/click để mở nắp phong thư.
- Lá thư trượt lên và mở thành nội dung đầy đủ.
- Responsive cho điện thoại và máy tính.

## Chạy local

Chỉ cần mở `index.html` bằng trình duyệt, hoặc dùng VS Code Live Server.

## Đưa lên GitHub Pages

1. Push các file vào branch `main`.
2. Vào **Settings → Pages**.
3. Ở **Build and deployment**, chọn **Deploy from a branch**.
4. Chọn branch `main`, folder `/ (root)`.
5. Save.

Sau khi deploy, GitHub sẽ cung cấp link web public.
